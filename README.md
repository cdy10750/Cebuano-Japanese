# Nihongo para sa Bisaya

セブアノ語話者が、英語を介さずセブアノ語から直接日本語を学ぶためのウェブアプリ。
現在はコース1（英語講師コース）のユニット1-1「レッスンを始める」が動く試作。

## 中身

| ファイル | 役割 |
|---|---|
| `index.html` `style.css` `app.js` | アプリ本体（ビルド不要、ログインなし） |
| `data/unit-1-1.json` | ユニット1-1のデータ（項目、問題、通し練習、解説） |
| `audio/1-1/` | 日本語の音声（ElevenLabs、eleven_v4、モノラル 56 kbps） |
| `tools/build-preview.mjs` | 1ファイルで開ける確認用ページ `preview.html` を作る |

## 動かし方

ファイルを直接開くとデータを読めないので、簡易サーバーで開く。

```
npx serve .
```

1ファイルで確認したいときは `node tools/build-preview.mjs` で `preview.html` を作って開く。

## 公開

Cloudflare Workers（静的ファイルのみ）。設定は `wrangler.jsonc`、配信しないファイルは `.assetsignore`。
Cloudflare の管理画面でこのリポジトリを接続すると、main に入った変更が自動で公開される。
公開先: https://nihongo-bisaya.bisayacebuano.workers.dev/

## できること

- レッスン4回分（新しいフレーズ → 場面から選ぶ → 聞き取り → 文頭ヒント付きスピーキング → 通し聞き、使い分け、通し練習）
- 復習（間隔反復。1日 → 3日 → 7日 → 14日 → 30日）
- ふりがなの表示切り替え
- セブアノ語の誤りを知らせる報告ボタン（端末に保存し、コピーしてDiscordに送る）
- 画面の言葉の切り替え（セブアノ語／日本語。日本語は確認用）

## まだないもの

- Discordログイン
- 場面動画
- ユニット1-2以降

## 注意

- 画面とデータのセブアノ語は、すべてネイティブ未確認。
- 進み具合は端末のブラウザに保存する（別の端末には引き継がれない）。
